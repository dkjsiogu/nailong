# 16 · 极光界面（0.31，历史）

> **0.32 起视觉基线见 [17 · 深岩界面](17-ui-deepslate.md)。** 本文保留 0.31 的极光/玻璃稿作为历史记录，不再作为新页面参考。

> 本文记录 0.31 的视觉基线。0.18–0.30 的浅色设计记录保留在 [15 · 界面设计系统](15-ui-design-system.md)；三套系统的信息架构相同，颜色、字体、层级和背景不同。

## 1. 概念

界面是一间**夜里的观测站**，不是后台管理台：

- 背景是极光、星场、月亮、龙形星座和方块山脊，安静地铺在窗口后面。
- 卡片是深色玻璃，标题用衬线体，正文用无衬线体；只有主操作和“正在进行”使用琥珀色。
- 启动台是一张完整的海报：当前版本和「开始游戏」在左，最近世界浮在右侧的夜空上，最近内容和快捷操作在下方。
- 每一页只有一个主行动；页面标题是“栏目名”，不是仪表盘 KPI。

## 2. 色板

| Token | 色值 | 用途 |
|---|---|---|
| `BG` | `#060A12` | 窗口底色 |
| `PANEL` | `#080D17` | 侧边栏、模态框内嵌区块 |
| `CARD` | `#0C1320` | 模态框、最深的卡片 |
| `SURFACE` | `#0E1725` | 页面卡片、列表容器 |
| `SURFACE2` | `#16223A` | 悬停、抬升、次级填充 |
| `LINE` | `#1E2B42` | 1 px 描边、分隔线 |
| `LINE_HI` | `#2E3F5C` | 悬停描边、次级按钮描边 |
| `INK` | `#EDF3FC` | 主文字、标题、图标 |
| `MUTED` | `#8FA0BA` | 次级说明、元数据 |
| `DIM` | `#5F7089` | 更弱的标签、分隔符 |
| `ACCENT` | `#FFB340` | 主按钮、选中、可用状态 |
| `ACCENT_HI` | `#FFD77A` | 主按钮亮端、焦点 |
| `ACCENT_LO` | `#FF7A1C` | 主按钮暗端、进度条 |
| `ACCENT_TEXT` | `#FFC66B` | 深色底上的强调文字 |
| `OK` / `SUCCESS` | `#4FE3B0` | 已就绪、安装完整、已启用 |
| `WARN` | `#FFB340` | 缺文件、可恢复警告 |
| `DANGER` | `#FF6B81` | 删除确认、错误 |
| `TEAL` | `#3FE0C5` | 极光、资源包标签、辅助信息 |
| `VIOLET` | `#9B7BFF` | 光影、极光、辅助标签 |

原则：

1. **琥珀只给行动和当前状态**。页面里同时出现两个琥珀实心按钮，说明层级错了。
2. 成功用青绿，错误用珊瑚红；警告用琥珀但只用描边/浅底，不用实心。
3. 正文不能低于 `MUTED`；`DIM` 只给“可以看不见”的注释。
4. 浅底强调色的对比度按 `ACCENT_TEXT` 检查，不直接用 `ACCENT` 写小字。

## 3. 字体

| 字体族 | 实际字体 | 用途 |
|---|---|---|
| `Proportional` | Noto Sans CJK / 微软雅黑 / PingFang | 正文、按钮、列表 |
| `bold` | Noto Sans CJK Bold / 微软雅黑 Bold | 列表主行、小标题、标签 |
| `display` | Noto Serif CJK Bold / SimSun / Songti | 页面大标题、启动台版本号、弹窗标题 |

- 页面标题 27–30 px display；启动台版本号 52 px display；弹窗标题 22–26 px display。
- 正文 10–13 px；元数据 8.5–10 px；不使用小于 8 px 的中文。
- 毛重不靠描边模拟；`display` 找不到时回退 `bold`，`bold` 找不到时回退系统常规。

## 4. 布局

- 侧边栏：1120 宽以上 236 px，窄窗 78 px（图标模式）。顶部品牌、当前版本卡、四个一级入口、底部账户/设置/版本号。
- 内容区：左右 28 px，最大宽度 1000 px；启动台 1120 宽时内容最大 1040 px。
- 启动台高度：常规 336 px 英雄区 + 212 px bento + 42 px 状态条；620 高窗口改为 300 + 200，并把 bento 内容压到 200 px。
- 卡片圆角：页面卡片 18，英雄区 24，bento 18，胶囊 12，输入框 8–9。
- 阴影：黑色 150 alpha、向下 22 px、模糊 52 px；深色主题下阴影只负责“浮起来”，不负责可见性，可见性靠 1 px `LINE`。
- 页面切换仍是 180 ms 淡入 + 10 px 上移；减少动效时直接完成。

## 5. 程序化背景

素材不随安装包分发。`backdrop.rs` 在第一次显示时按内容区尺寸渲染两种场景：

1. **Window**：低对比极光、星场、月亮、三层方块山脊；给所有页面当底。
2. **Hero**：更高对比的极光、星场、月亮、龙形星座、方块山脊与树影，左侧和底部把文字遮罩直接烘进纹理，保证标题对比度。

实现细节：

- 逐像素生成，64×64 噪声场 + 三条正弦极光带 + 分块山脊；星点按确定性 LCG 撒布，不依赖网络和素材。
- 生成结果缓存为 `TextureHandle`，只在窗口尺寸变化时重建；绘制阶段只画一张纹理。
- 0.31 在 Xvfb + llvmpipe、窗口聚焦、鼠标移开后复测空闲 CPU 为 0.0%。
- 英雄区纹理自带圆角透明通道，卡片边框只负责描边，不会出现“方形图盖在圆角卡上”。

## 6. 组件

- **主按钮**：琥珀渐变、深棕文字、1 px 亮边、接触阴影；悬停亮 6%，按下下沉 1 px。
- **次按钮**：`SURFACE2` 玻璃、`LINE_HI` 描边、`INK` 文字；悬停描边转 `ACCENT_HI`。
- **幽灵按钮 / 返回**：透明底、MUTED 文字、无描边；仅在悬停时出现下划线。
- **内容标签**：`Mod` 琥珀、`资源包` 青、`光影` 紫、其他 `MUTED`；标签底色是同色 16–20 alpha。
- **开关**：36×20，开=琥珀轨道+深色滑块，关=深蓝轨道+`MUTED` 滑块；减少动效时立即到位。
- **输入框**：`#070C15` 底、`LINE` 描边、9 px 圆角；聚焦由光标和 1 px 描边强调，不加发光。
- **弹窗**：`CARD` 底、`LINE` 描边、20 px 圆角；遮罩为 `#02050A` 168 alpha；设置弹窗在 620 高窗口内滚动正文，底部按钮固定可见。
- **状态胶囊**：英雄区顶部、列表统计使用 12 px 圆角胶囊，底色 `#060B14` 176 alpha。

## 7. 页面要点

- **启动台**：英雄区是唯一的主视觉；不放重复的页面标题。左上状态、右上版本切换；左下主行动；右下最近世界卡片；下方最近内容 + 快捷操作 + 系统状态条。
- **版本**：左栏版本列表，右栏“VERSION DETAIL”衬线标题、状态行、概览数字、安装信息。
- **内容**：页头 `LIBRARY` + 衬线“内容”；已安装/发现、类型胶囊、搜索/安装目标在一条工具带；1120 宽 4 列，900 宽 3 列。
- **存档**：页头 `SAVES` + 衬线“存档”；左侧世界列表，右侧整块玻璃卡包住快照标题和列表。
- **安装**：页头 `INSTALL` + 衬线“安装游戏”；左侧版本/加载器选择，右侧安装摘要和主按钮。
- **进度**：居中的玻璃卡，衬线标题 + 大号百分比 + 带扫光的进度条。
- **设置**：四个内嵌区块（账户、玩家名/内存/Java、目录、减少动效）+ 诊断；快捷键提示放在诊断下方。

## 8. 验证

- 1120×720：启动台、版本、安装、内容已安装/发现/搜索/详情、存档、进度、首次启动、设置、账户、登录、登录失败、恢复点、安装确认、空内容库、空存档。
- 900×620：启动台、版本、内容、存档、安装、设置；设置正文可滚动，底部「完成」始终可见。
- 动效：侧边栏切页、发现、详情返回、启动台；`docs/screenshots/motion.gif` 约 17 秒。
- 性能：空闲 0.0% CPU（Xvfb + llvmpipe，窗口聚焦，指针停在角落）。
