# 21 · 手感

> 0.36 的起点是一次实际使用里碰到的四个问题：「3 个已禁用」看得见却点不了，长列表没有像样的搜索；启动失败后「查看日志」要绕设置 › 数据目录 › logs 三层；Mod 不能直接从文件夹拖进来；内容页没有「打开文件夹」。
>
> 它们不是四个孤立的缺功能，而是同一类毛病：**界面告诉了玩家一件事，却没让玩家顺手去做下一步。** 这一页把原因和规则写下来，以后每个页面都按它检查。

## 1. 四个问题背后的原因

| 碰到的问题 | 背后的毛病 |
|---|---|
| 「3 个已禁用」「4 组重复」只能看 | 状态是写给人看的文字，不是入口。玩家看到数字，下一步一定是「是哪几个」，界面却要他自己去长列表里找 |
| 只有一个很小的「筛选」框 | 搜索被当成次要功能藏起来：没有放大镜，没有快捷键，和状态筛选不能叠加 |
| 查看日志要绕三层 | 出错时把玩家送去找文件，而不是把答案端过来。日志散在设置里的一小块和数据目录里的文件之间，还得自己从几千行里找红字 |
| 不能拖、不能打开文件夹 | 启动器把文件藏在自己后面。玩家的 Mod 本来就在文件管理器里，绕一圈文件选择框是多余的 |

## 2. 规则

1. **数字就是入口。** 显示一个数量或状态（已禁用、可更新、重复、缺文件），点它就只看这些；再点一次回到全部。有颜色的数字只用在需要注意的状态上。
2. **长列表都能搜。** 搜索框带放大镜、写清搜什么，`Ctrl+F` 直接聚焦，`Esc` 清空。搜索和状态筛选叠加，筛选后告诉玩家显示了几项，空结果给一个「清除筛选」。
3. **出错就把答案端到眼前。** 错误提示后面的「查看日志」一步打开这次的游戏输出：能认出的原因放在最上面，用玩家能照着做的话说（缺哪个前置、内存不够、Java 太旧、哪个参数不认）；认不出就给最后一个错误。错误行标红，「只看错误」一键过滤，复制、用编辑器打开、在文件夹中显示都在底部。
4. **文件就是文件。** 能放文件的地方都能直接拖进来，一次拖很多个、拖整个文件夹都行；拖着经过窗口时就说清楚会装到哪、装几个，不能装时说为什么；放内容的页面都有「打开文件夹」，每一项都能「在文件夹中显示」。
5. **外面的改动自己出现。** 玩家在文件管理器里加删了文件，回到窗口时列表已经是新的，不需要找「重新扫描」。
6. **刚做的事看得见。** 导入后清掉筛选，新的那几项标「刚导入」；全是另一类内容时切到那一类。
7. **一批事只打扰一次。** 拖进 20 个 Mod 只留一个恢复点、只出一条提示（导入了几个、跳过了几个已经装过的）。

## 3. 0.36 落在哪

**内容 › 已安装**

- 第一行：左边搜索框（`Ctrl+F`），右边「打开文件夹」「检查更新」「导入文件」（可多选）。
- 第二行：状态胶囊「全部 · 已启用 · 已禁用 · 可更新 · 重复」，只显示有东西的；右边是「恢复点」「重新扫描」两个次要链接。
- 重复的 Mod 按组挨在一起，提示「留一份，其余禁用或删除」；列表上方的重复提醒带「只看这些」。
- 每一项的「⋯」里是「在文件夹中显示」（Windows 用 `explorer /select`，Linux 用 freedesktop 的 FileManager1，打不开时退回打开目录）。
- 窗口重新拿到焦点时比对三个内容目录的文件名、大小和修改时间，变了就重扫。

**拖放（所有页面）**

- 按内容认文件，不只看扩展名：`.jar` 是 Mod；`.zip` 里有 `pack.mcmeta` 是资源包、有 `shaders/` 是光影、有 `modrinth.index.json` / `manifest.json` / `mmc-pack.json` / `instance.cfg` 是整合包；认不出的 zip 在资源包、光影页按当前页处理。
- 在内容页装到上面选的目标，其他页面装到当前版本；原版不能装 Mod，会在悬停时就说。
- 整批一个恢复点；已经装过的（包括禁用的 `.disabled`）跳过。单个整合包照旧走整合包安装。

**日志**

- 新的日志窗口（`Ctrl+L`，或任何错误提示后的「查看日志」）：游戏输出 / 崩溃报告（这次启动之后的 `crash-reports` 或 `hs_err`）/ 启动器三个标签，游戏运行中每秒跟着刷新，只读文件末尾 4 MB。
- 游戏异常退出时，提示直接带上认出的原因，例如「游戏异常退出（代码 1）：缺少前置 Mod「flywheel」（create 需要它）」。
- 设置里不再嵌一小块日志，只留一个入口。

## 4. 还没做到的

- 存档页还不能把世界文件夹或 zip 拖进来导入。
- 版本页列表短，暂时没有搜索。
- 日志窗口不能跳到某一行，长日志靠「只看错误」和搜索。
- 拖放在 Linux X11（含 XWayland）上实测过；Windows 实机还没试。
