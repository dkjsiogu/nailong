# 13 · UI 低保真线框与交互状态

> 本文把 [08 界面与交互](08-ui-ux.md) 的页面规格画成可评审的低保真线框，并定义关键状态。
> 目标不是视觉稿，而是先确认**信息层级、点击路径、状态反馈**；高保真在 egui 原型中迭代。

## 1. 画布与响应式

| 项 | 值 |
|---|---|
| 最小窗口 | 900 × 600 |
| 默认窗口 | 1280 × 800 |
| 大屏 | 内容最大宽度 1200，居中；两侧留白 |
| 侧边栏 | 展开 200 px / 收起 72 px（< 1100 px 自动收起） |
| 内容边距 | 24 px（小窗 16 px） |
| 卡片网格 | 最小卡宽 240 px；列数 = floor(可用宽度 / 264) |
| 标题栏 | v1 使用系统原生标题栏 |

## 2. 导航模型

```text
┌──────────────┬────────────────────────────────────────────────────┐
│ nailong      │  实例                    [搜索]      [头像] [设置] │
│              │                                                    │
│  ● 主页      │  ┌──────────┐ ┌──────────┐ ┌──────────┐           │
│  ○ 实例      │  │ 实例卡片 │ │ 实例卡片 │ │ + 新建   │           │
│  ○ 下载  ②   │  └──────────┘ └──────────┘ └──────────┘           │
│  ○ 设置      │                                                    │
│              │                                                    │
│  [头像] 名字 │                                                    │
└──────────────┴────────────────────────────────────────────────────┘
```

- 侧边栏四项：主页（最近/推荐）、实例（全部）、下载（进行中/历史）、设置。
- "主页"和"实例"在 v1 可以合并为一个实例页；侧边栏保留"主页"作为启动后的默认页。
- 账户胶囊固定在侧边栏底部；点击打开账户弹层。
- 有任务时，底部出现全局任务条（可折叠）：

```text
┌──────────────────────────────────────────────────────────────────┐
│ ↓ 正在下载 1.21.11 + Fabric    资源 42% · 18.4 MB/s · 剩余 1:20  [取消] │
└──────────────────────────────────────────────────────────────────┘
```

## 12. 交互规则

1. **点击目标** ≥ 32×32 px；主要按钮高度 36；卡片整块可点。
2. **键盘**：Tab 顺序=侧边栏→内容→底部；Enter 主操作；Esc 关闭弹层；空格切换。
3. **焦点**：2 px accent 描边；不可见焦点视为缺陷。
4. **危险操作**（删除实例/清缓存/停止游戏）二次确认，默认焦点在"取消"。
5. **进度**：确定进度显示百分比/速度/剩余；不确定进度显示动画 + 阶段文字；完成即消失。
6. **错误**：标题一句话 + 原因 + 建议 + 2–3 个动作；不显示堆栈（详情里可看）。
7. **拖放**：拖入 `.mrpack`/zip/实例文件夹显示"导入到 nailong"覆盖层。
8. **空状态**：每个列表都有；不显示空白页。
9. **文案**：中文优先，避免"失败了"；用"下载中断，请重试"。

## 13. 响应式规则

| 宽度 | 行为 |
|---|---|
| ≥ 1200 | 侧边栏展开 200；卡片 4 列 |
| 1000–1199 | 侧边栏收起 72；卡片 3 列 |
| 900–999 | 侧边栏收起；卡片 2 列；设置页单列 |
| < 900 | 不允许（最小窗口 900） |

## 14. 待评审问题

1. **主页与实例页是否合并**？当前方案保留两个入口，但内容相近；可合并以减少导航。
2. **实例卡片密度**：大卡（图标+两行）vs 紧凑列表；低配用户可能更喜欢列表。
3. **全局任务条**位置：底部 vs 顶部；底部不遮挡内容，但与状态栏冲突。
4. **启动后行为**：隐藏启动器 / 保持 / 关闭；默认建议"保持"（便于看日志）。
5. **错误详情**：弹窗 vs 侧滑面板；侧滑不打断操作。
6. **原生标题栏**：v1 使用系统标题栏（Snap/无障碍更好）；是否在 v1.1 自绘。
