# 25 · 多账户和截图

> 0.40 做了两件事：
>
> - **账户**：支持多个微软正版、外置登录（authlib-injector）和离线账户，在侧栏左下角切换。
> - **截图**：每张截图记录时间、地点和人物，截图页按这几项浏览。
>
> 用户提这个需求时的原话是：「一张图片四个信息，时间地点人物，地点包含是哪个版本的、哪个存档」。

## 1. 账户

### 1.1 三种账户

| 类型 | 怎么加 | 启动时 | 凭证 |
| --- | --- | --- | --- |
| Microsoft 正版 | 浏览器授权；可添加多个 | `user_type=msa`，带令牌、UUID、XUID | 刷新令牌；过期前 5 分钟自动刷新 |
| 外置登录 | 填皮肤站地址，再填账号和密码；一个号有多个角色时让玩家选 | `user_type=mojang`，并在最前面挂 `-javaagent:authlib-injector.jar=<API>` 和预取的元数据 | accessToken 和 clientToken。**不保存密码** |
| 离线 | 只填名字 | `user_type=legacy`，UUID 按 `OfflinePlayer:<名字>` 算，和游戏的算法一致 | 无 |

账户都存在数据目录的 `accounts.json` 里，Unix 上权限是 600。下面这些操作都会立刻写盘：添加、移除、切换、刷新凭证。

升级时自动迁移，旧数据不会丢：

- 0.40 以前只有一个微软账户，存在 `account.json`。第一次启动 0.40 时把它搬进 `accounts.json`，搬完删掉旧文件，免得凭证留两份。
- 一个账户都没有时，把以前设置里的玩家名变成一个离线账户。

### 1.2 外置登录（authlib-injector）

照着 [authlib-injector 的启动器规范](https://github.com/yushijinhun/authlib-injector/wiki) 做，代码在 `core::yggdrasil`：

- **找接口地址**：只填 `littleskin.cn` 也行。没写协议就补上 `https://`，再按响应头 `X-Authlib-Injector-API-Location` 找到真正的接口地址。https 指向 http 的跳转不跟。服务器是 http 的，界面上用红字提醒密码会明文传输。
- **登录**：`authserver/authenticate`。只有一个角色就直接用；有多个就列出来让玩家选，选好后用 `authserver/refresh` 带上 `selectedProfile` 绑定。没有角色时提示玩家先去网站上创建。
- **启动前**：先 `validate`。不行就 `refresh`。还不行就把账户标成「需要重新登录」，弹出重新登录窗口：服务器和账号已经填好，只需要再输一次密码。连不上服务器时，提示检查网络或换成离线账户。
- **认身份**：一个外置账户由「服务器 + 角色 UUID」确定。同一个人再登录一次只更新凭证，不会多出一个账户。
- **authlib-injector**：第一次用外置账户启动时下载，按 `latest.json` 里给的 SHA-256 校验，存在数据目录的 `authlib-injector/` 下。官方连不上时走 BMCLAPI 的镜像（`/mirrors/authlib-injector`）。下载失败但本地有旧版时，用旧版。
- **服务器报错**：翻成能照着做的话。例如 LittleSkin 回的「用户名或密码错误。Incorrect username or password.」显示成「账号或密码不对」。
- **拖进窗口做不到**：规范建议支持把皮肤站网页上的链接拖进窗口，但窗口库（winit）只接收拖进来的文件，接收不了文字。所以改成粘贴：把 `authlib-injector:yggdrasil-server:…` 这样的链接粘贴进服务器地址栏，会自动换成里面的接口地址。

### 1.3 界面

- **侧栏左下角**：显示正在用的账户，有皮肤就显示皮肤的脸。账户需要重新登录时，头像右上角有一个黄点。
- **点开账户列表**：列出全部账户。
  - 每行写着名字和类型，例如「Microsoft 正版」「LittleSkin · 外置登录」「离线」。正在用的那个标「● 正在用」。
  - 点一行即切换，下次启动生效。点到需要重新登录的账户时弹出重新登录窗口。
  - 每行右边的 `⋯` 和右键是同一份菜单：复制名字、复制 UUID（带短横线）、打开皮肤站、重新登录、移除。移除前会确认一次。
- **添加账户弹窗**：三个选项卡，分别是 Microsoft、外置登录、离线。
  - 外置登录时，用过的服务器显示成标签，点一下就填好。
  - 皮肤站声明登录名不是邮箱时，标签写「账号」，不写「邮箱」。
- **设置**：账户卡片显示正在用的账户和一共有几个，按钮是「切换或添加」。以前的「玩家名」输入框去掉了，离线账户的名字在添加账户时填。
- **头像**：从皮肤图上切出脸（8×8），再盖上帽子那一层。高清皮肤按比例取像素。皮肤图缓存在 `cache/cairn/skins/`。

「不用像素元素」这条界面规则管的是界面装饰。皮肤是玩家自己的形象，不算装饰，所以头像用皮肤的脸。

## 2. 截图：时间、地点、人物

### 2.1 每张图知道什么

| | 从哪来 |
| --- | --- |
| 时间 | 游戏按本地时间给截图起名（`2026-11-07_21.34.12.png`），从文件名读。名字不合这个格式就用修改时间 |
| 地点：版本 | 截图时记下的版本名。没记下的，用截图所在游戏目录对应的版本 |
| 地点：存档或服务器 | 截图时记下的。以前的截图从游戏日志推断 |
| 人物 | 截图时用的账户：名字、UUID 和类型（正版、LittleSkin、离线）。以前的截图从日志里的 `Setting user:` 推断 |

### 2.2 截图那一刻就记下来

从 Cairn 启动的游戏，启动器会一边读游戏的输出，一边判断现在在哪：

- `Starting integrated minecraft server`：进了单人世界。是哪个世界，看 `saves/` 下哪个世界的 `session.lock` 在这局游戏开始后最新（世界一打开就会写这个文件）。这个办法比日志里的世界名可靠：两个世界同名时，文件夹名还是不一样的。
- `Connecting to <主机>, <端口>`：进了服务器。默认端口 25565 不写出来。
- 一行聊天消息里出现按时间起的 PNG 文件名：就是刚保存的截图。这行消息会随游戏语言翻译（中文是「已将截图保存为…」），所以不认文字，只认 `[CHAT]` 和文件名的格式。

认出截图后，把信息写进这张 PNG 自带的文字块，像照片的 EXIF：

- 文字块的类型是 iTXt，关键字是 `Cairn`，内容是 JSON。放在 IHDR 后面，读的时候不用读整张图。
- 写入是原子的：先写临时文件，再改名替换。像素一个字节都不动，原来的修改时间也保留。
- 写进图片以后，日志删了、图片挪到别处，这些信息都还在。
- 设置里可以关掉「截图写入地点和人物」。关掉后只记在数据目录的 `shots.json` 里，图片不改。

### 2.3 以前的截图

第一次打开截图页时，顺便翻一遍每个游戏目录的日志：`logs/*.log.gz` 和 `latest.log`。按同样的规则推断每张截图在哪、是谁截的，结果存进 `shots.json`。之后日志删了也不丢。读过的日志按文件大小记下，不再重复读。

- 日志里的世界名来自 `ServerLevel[名字]`。老版本的日志写的是 `Saving chunks for level '名字'` 或 `Preparing level "名字"`。按名字去 `saves/` 下找对应的文件夹。
- 实在认不出来的，归到「未知地点」和「未知玩家」。

几处来源都有信息时，按这个顺序取：

1. 图片里写的：截图时记下的，或者玩家手动指定的。
2. `shots.json` 里的：从日志推断的。
3. 截图所在的游戏目录：只能知道是哪个版本。

### 2.4 截图页

侧栏第 5 项「截图」（Ctrl+5）。四个视图：

- **总览**
  - 顶部一排四格：一共多少张、从什么时候到现在、几个地方、几个人。每格都能点进去。
  - 最近 12 张。
  - 每个月截了多少：最近一年，每月一根柱子，点一根就看那个月。
  - 截得最多的 4 个地方。
  - 每个人：头像、名字和张数。
- **时间**
  - 最近一周按天分组（「今天」「昨天」「11月3日 周二」），更早的按月分组。
  - 每组右边写着在哪截的、几张。
  - Ctrl+滚轮在三种大小之间切换。
  - 只画看得见的那几行，几千张也不卡。
- **地点**：先按版本分组，组里再按存档或服务器，一个地方一本相簿。服务器名优先用 `servers.dat` 里玩家起的名字。
- **人物**：每个账户一行，有头像、类型、张数、去过几个地方，后面跟着最近 6 张。

点进相簿、某个人或某个月，就到「时间」视图，加上对应的筛选。筛选条件在顶上显示成标签，点 × 去掉。

搜索框能搜存档名、服务器、人名、版本和日期，比如「10月3日」或「2026-10-03」都行。

### 2.5 看大图

启动台那一排截图和截图页用的是同一个看图器：

- **当前这一组翻页**：←/→ 只在当前这一组里翻，比如这个时间段、这本相簿或这个人。底部有一排缩略图。
- **缩放和平移**
  - 滚轮缩放，以鼠标为中心。
  - 双击在「适应窗口」和「原尺寸」之间切换。
  - 放大后可以拖动，图只画在顶栏和底栏之间。
- **顶栏**：时间、地点、人物（带头像）、分辨率和文件大小。
- **操作**
  - 复制图片：Ctrl+C 或右键。
  - 在文件夹中显示。
  - **设为世界图标**：从中间裁一块正方形，缩到 64×64，写成存档文件夹里的 `icon.png`。
  - **移到回收站**：Delete 键也行，要点两次才执行。Linux 上用 `gio trash`，Windows 上用系统回收站。不会直接删掉。

### 2.6 和别的页面怎么连

- **启动台**：「截图 N 张 ›」和最后一格的「+N」点了都去截图页，筛出这个版本的截图。
- **存档页**：选中的世界旁边写着「N 张截图 ›」，点了去这个世界的相簿。

## 3. 测试

- **core**
  - 账户：迁移旧的 `account.json`；同一个人再登录只更新、不重复；离线账户改名和 UUID 一致；`accounts.json` 里不出现密码。
  - 外置登录：ALI 的相对地址；元数据解析；粘贴链接；皮肤地址；错误翻译。另外有一个需要连外网的测试（平时不跑），实测了 LittleSkin 和 authlib-injector 的下载。
  - 截图
    - PNG 信息来回读写：像素不变，修改时间不变，再写一次是替换不是叠加。
    - 文件名里的时间；中英文的截图消息。
    - 在一份日志里跟着世界和服务器走。
    - 截图那一刻写入信息，也测了关掉「写进图片」的情况。
    - 列出截图时，图片里写的优先。
    - `servers.dat` 的服务器名。
- **界面**：切皮肤脸；筛选和搜索；按天和按月分组；缩略图缓存；设世界图标。
- **截图核对**
  - 测试数据：用生成的 35 张图，分布在两个游戏目录、三个世界、两个服务器、三个账户，时间跨一年。
  - 核对过的界面：截图页四个视图、看大图（含放大）、账户列表、添加外置账户（实连 LittleSkin）、深浅两种主题。
