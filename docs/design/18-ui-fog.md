# 18 · 雾蓝界面

> 0.33 起 `crates/nailong-ui` 的唯一视觉基线。[15](15-ui-design-system.md)、[16](16-ui-aurora.md)、[17](17-ui-deepslate.md) 只作历史记录，信息架构仍以 [产品 brief](../product/00-brief.md) 为准。

## 1. 原则

参考 Screeps 的克制感：简洁、哑光、高级，操作舒适。

1. **颜色要有理由。** 大面积只用灰，雾蓝只表示主行动、当前项和需要注意的数据。
2. **层级靠字号和灰度。** 少用粗体，少用边框，不靠卡片堆叠。
3. **图形要表达状态。** 不放纯装饰图。
4. **动效只回应变化。** 没有发生什么，界面就不动。

明确不要：霓虹、发光、渐变、毛玻璃、纹理背景、吉祥物、像素和方块元素、大面积高饱和色、英文小标题。

## 2. 颜色

深色和浅色共用同一组 token，代码里不再写死颜色。设置里提供「跟随系统 / 深色 / 浅色」，默认跟随系统，选择写入 `ui.json`。

| Token | 深色 | 浅色 | 用途 |
|---|---|---|---|
| `bg` | `#1B1D22` | `#F1F1EE` | 窗口、侧边栏 |
| `surface` | `#22252B` | `#FAFAF7` | 确实需要成块的内容、弹窗、输入框 |
| `wash` | `#272A31` | `#E4E5E4` | 当前导航项、悬停行 |
| `hairline` | `#2D3037` | `#DBDBD6` | 分隔线、卡片边 |
| `control` | `#666B76` | `#85888F` | 输入框和开关的边框 |
| `ink` | `#DFE2E8` | `#2B2D32` | 主文字 |
| `sub` | `#A0A5B0` | `#5C5F66` | 次级文字 |
| `dim` | `#888D98` | `#6B6E74` | 弱标签、元数据 |
| `dot` | `#7C818C` | `#85888F` | 圆环里的普通点和刻度 |
| `accent` | `#8496C2` | `#52648F` | 主按钮、当前状态、可更新 |
| `on-accent` | `#14161B` | `#F6F6F3` | 主按钮和其他实色块上的文字 |
| `ok` | `#88A896` | `#517662` | 成功 |
| `warn` | `#BFA173` | `#856936` | 缺文件、需要处理 |
| `danger` | `#C98A82` | `#A5544C` | 删除、错误 |

- `sub`、`dim`、`warn`、`ok`、`danger` 在定稿样稿的基础上做了微调，让正文级文字在 `bg` 上达到 4.5:1，`control` 达到 3:1。
- 一屏最多一个 `accent` 实色主按钮，其余按钮用线框或文字样式。
- 项目没有图标时用 `wash` 底配 `sub` 首字母，不按项目分配彩色。
- 内容类型靠文字区分，不用颜色区分。

## 3. 字体

| 用途 | 字号 | 字重 |
|---|---:|---|
| 启动台版本号 | 64（名称过长时 40） | 细体 |
| 页面标题 | 24 | 常规 |
| 区块标题、列表主行 | 15 | 粗体 |
| 正文、按钮、导航 | 14–15 | 常规 |
| 次级说明、元数据 | 13 | 常规 |

中文用系统字体：Linux 是 Noto Sans CJK，Windows 是微软雅黑，字重只用常规和粗体。

**启动台的细体：** 系统的 Noto Sans CJK 通常只有 Regular 和 Bold，所以拉丁字符和数字用 egui 默认字体里自带的 Ubuntu Light，不增加发布体积。中文名称的版本回退到常规字重。

## 4. 几何与间距

- 圆角：控件和卡片 4，弹窗 6。
- 边框：1 px。不用阴影，弹窗靠遮罩和 `surface` 区分，菜单用很淡的投影。
- 间距基数 4，常用 8 / 12 / 16 / 24 / 36；页面左右留 36。
- 分块优先用留白和细线，其次才用卡片。
- 窗口尺寸：1120×720 为基准，最小 900×620。

## 5. 组件

| 组件 | 样式 |
|---|---|
| 主按钮 | `accent` 实色、`on-accent` 文字，高 40；悬停略提亮，按下略压暗 |
| 次按钮 | 透明底、`hairline` 边，悬停填 `wash` |
| 文字按钮 | `sub` 文字，悬停变 `ink` |
| 危险按钮 | 平时同次按钮，文字用 `danger`；二次确认时才用实色 |
| 导航项 | 高 36，图标 + 文字；当前项填 `wash`、文字用 `ink`，其余用 `sub` |
| 列表行 | 行间细线，悬停填 `wash`，操作靠右 |
| 输入框 | `surface` 底、`control` 边，聚焦时边变 `accent` |
| 开关 | 关闭时 `control`，打开时 `accent`，滑块 150 ms 到位 |
| 进度条 | 高 4，`hairline` 轨道，`accent` 填充 |
| 空状态 | 一句标题、一句说明、一个行动，不放插图 |
| 错误 | 一句能行动的话，原始错误进日志 |

键盘：所有可操作元素都能用 Tab 聚焦，聚焦时显示 2 px `accent` 外框。现有快捷键保留。点击区域高度不小于 32。

## 6. 页面

始终是四个一级入口：启动台、版本、内容、存档。侧边栏宽 190，窄窗口缩成 64，只留图标。侧边栏和内容区同底色，用一条 `hairline` 分开。

**启动台（定稿样稿）：**
- 左上：加载器和状态、版本号、「开始游戏」、「切换版本」。
- 右上：状态圆环。
- 中部：最近世界、内容、备份三栏，用竖向细线分隔，整栏可点。
- 底部：Java、内存、拖入提示，用 `dim`。620 高的窗口隐藏这一行。

**其他页面沿用同一结构：**
- **版本：** 左边列表，右边详情，信息用「标签—值」行，不套多层卡片。
- **内容：** 页头放标题、搜索和安装目标；发现页用网格，每项一块；已安装页用列表行。
- **存档：** 左边世界，右边快照时间线。
- **安装：** 左边选择，右边摘要和主按钮。
- **进度：** 居中显示大百分比、进度条、当前阶段和取消按钮，同时显示放大的状态圆环。
- **设置、账户、恢复点、确认弹窗：** `surface` 底，最多一个主按钮，Esc 可关闭。

## 7. 状态圆环

圆环从内到外有四层。平时没有文字。

| 层 | 含义 | 数据来源 |
|---|---|---|
| 中心圆点 | 能否启动 | 版本健康检查、当前任务 |
| 内环 | 文件完整度或安装进度 | `health.missing`、`Progress` |
| 中环 | 每个 Mod 一个点 | 已安装索引、更新检查结果 |
| 外圈刻度 | 这个版本所有世界的快照，最新的在最上方 | `snapshots::list` |

**状态：**

| 状态 | 表现 | 主按钮 |
|---|---|---|
| 可以启动 | 雾蓝圆点，内环满圈 | 开始游戏 |
| 有更新 | 可更新的 Mod 点放大并变雾蓝 | 开始游戏 |
| 缺文件 | 圆点和内环变 `warn`，内环缺一段 | 补全文件 |
| 安装中 | 内环按进度走，外面一圈虚线缓慢旋转 | 取消安装 |
| 游戏运行中 | 从中心缓慢向外扩散圆圈 | 查看运行状态 |

**悬停：** 当前层变亮，其他层降到 22% 透明度，旁边 180 ms 内浮出说明卡片。

| 位置 | 动效 | 说明 |
|---|---|---|
| 中心圆点 | 轻微弹大 | 能否启动、原因 |
| 内环 | 线条变粗 | 文件是否完整，或安装进度 |
| 中环 | 点依次向外弹开 | 启用、禁用、可更新数量 |
| 外圈 | 外扩并微转 | 快照数量、最新时间 |

**点击：** 中心圆点执行主按钮的动作，内环进版本详情，中环进内容，外圈进存档。

**键盘：** Tab 聚焦圆环，方向键在各层之间切换，说明卡片同样显示，Enter 或空格触发。

**边界：**
- Mod 超过 40 个时，中环改成按比例的分段弧，只区分启用、禁用和可更新。
- 外圈最多显示 60 根刻度，超出时只显示最新的 60 份。
- 没有 Mod 或快照时，只留一条细线，悬停时说明怎么开始。
- 「有更新」只反映上一次更新检查的结果。这一版不新增后台联网。
- 运行中只显示已运行时长。启动器目前不采集游戏内存，不显示内存占用。
- 缺文件的数量可以显示，大小没有现成数据，这一版不显示。
- 数据只在进入页面和内容变化时读取并缓存，不逐帧读盘。

## 8. 动效

| 类型 | 时长 | 说明 |
|---|---|---|
| 悬停、按下 | 100–150 ms | 只变颜色，不位移 |
| 圆环悬停 | 180–320 ms | 允许轻微回弹，只用在圆环上 |
| 圆环状态变化 | 400–700 ms | 进度和颜色平滑过渡 |
| 换页 | 150 ms | 内容淡入，上移 6 px |
| 弹窗 | 150 ms | 淡入，上移 6 px |

**性能：** 动画结束就不再请求重绘，空闲 CPU 必须是 0。持续动画只有两处：安装中的虚线，以及窗口聚焦时游戏运行中的扩散圈。

**减少动效：** 打开后所有过渡直接到位，持续动画停止，状态仍靠颜色和形状表达。

## 9. 代码位置

- `theme.rs`：两套颜色、外观设置，以及对比度测试。
- `motion.rs`：按钮、进度条、焦点外框和动效工具。
- `rings.rs`：状态圆环。

## 10. 验收

- 两套配色的所有页面在 1120×720 和 900×620 下都不裁切、不越界。
- 正文级文字对比度不低于 4.5:1，控件边框不低于 3:1。
- 除 `theme.rs` 外不写死颜色。
- 圆环的五种状态、四层悬停和点击都能用，键盘也能操作。
- Xvfb 下窗口聚焦、鼠标移开后空闲 5 秒，CPU 为 0.0%。
- 减少动效打开后没有持续动画。
- `cargo fmt --check`、`cargo clippy --all-targets -- -D warnings`、`cargo test --workspace` 全部通过。
- 还要在 Windows 实机上检查字体和 125%/150% DPI。这一项此前从未验证过，需要有 Windows 环境才能完成。
